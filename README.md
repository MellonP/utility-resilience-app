# Utility Resilience App for Piet Retief 💧⚡

A community-driven mobile application that empowers residents of Piet Retief and similar communities to report, monitor, and receive timely updates about water and electricity outages while promoting collective action and resilience.

## 🎯 Vision

To develop a hyperlocal, bilingual platform that addresses both water and electricity infrastructure challenges in under-resourced South African communities through smart data and community power.

## 🔍 Problem Statement

Piet Retief, located in Mpumalanga, faces ongoing water and electricity outages that disrupt daily life and economic activity. Current solutions focus on one utility at a time, leaving gaps in communication, preparation, and accountability.

## ✨ Solution Overview

An integrated community-driven app that enables:
- Real-time tracking of water and electricity outages
- Crowd-sourced reporting from residents
- Notifications and alerts about scheduled or unexpected outages
- Resource locator for water trucks, generators, and communal access points
- Data insights and trends for civic engagement

## 🏁 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/utility-resilience-app.git
   cd utility-resilience-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` to view the app

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run build:dev` - Build in development mode
- `npm run lint` - Run ESLint
- `npm run preview` - Preview production build

## 🎨 Unique Value Proposition

Unlike existing single-utility apps (e.g., EskomSePush), this platform is:
- **Hyperlocal** - Focused on specific communities
- **Bilingual** - Supporting isiZulu/English
- **Dual-utility** - Addressing both water and electricity
- **Community-driven** - Powered by resident reports and engagement

## 💼 Revenue Model

- **Freemium** access for users
- **Government/NGO partnerships** for sponsorship and data reporting
- **Local advertising** (water tank suppliers, generator services)

## 🗺 Market Opportunity

### Identified Gaps
- No app currently offers integrated electricity + water outage tracking for rural/underserved towns
- Lack of language localization for smaller communities
- Limited community interaction and coordination features
- No predictive data models for outage forecasting

### Competitive Advantage
- First dual-utility tracking app for South African townships
- Community-centric design with local language support
- Predictive analytics using crowd-sourced data
